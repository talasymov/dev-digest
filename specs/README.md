# specs

One spec per feature, written **before** the code. Cross-package features live here;
single-package features live in `<package>/specs/`.

- Name: `<id>-<slug>.md`, e.g. `L01-run-cost-badge.md`.
- Start from [`_template.md`](_template.md) (or run `/new-spec <id> <slug>`).
- Update `Status` when the feature ships; keep the spec as the record of intent.
